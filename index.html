AI Image Studio V6.8

Ưu tiên tạo và sao chép prompt. Các công cụ tạo/xuất ảnh bằng OpenAI và Gemini được thu gọn, chỉ hiện khi thím chủ động mở; mọi tính năng cũ vẫn được giữ nguyên.

Đang ẩn các menu API để giao diện gọn hơn.

1. Kết nối dịch vụ (Provider Setup)

Backend local của thím. Không cần đăng nhập bằng mật khẩu; API key vẫn được giữ trong file .env, không đưa vào trình duyệt.

Chế độ local: backend chỉ lắng nghe trên máy này (127.0.0.1). Không chia sẻ backend ra mạng công cộng.

1. Tạo prompt (Prompt Builder)

Ứng dụng được điền sẵn một ví dụ chân dung điện ảnh để thím xem cách chia prompt theo từng mục. Thím có thể sửa, xóa hoặc thay toàn bộ nội dung trước khi tạo prompt.

Bố cục và máy ảnh (Composition & Camera)

Làn da nhân vật (Skin Realism)

Chọn cách thể hiện da. Ứng dụng tự ghép mô tả phù hợp vào prompt cuối theo ngôn ngữ đã chọn; mặc định là da tự nhiên có khuyết điểm nhẹ.

Ảnh tham chiếu gửi API (API Reference Images)

Phần tải ảnh tham chiếu chỉ cần mở khi sử dụng API. Chỉ tải ảnh bạn có quyền sử dụng.

PNG, JPEG, WebP. Giới hạn mặc định 4 ảnh, mỗi ảnh tối đa 10 MB.

Chế độ người mẫu (Character Reference Mode)

Chế độ mới: ưu tiên giữ khuôn mặt, kiểu tóc và tỷ lệ vóc dáng của ảnh mẫu; cho phép thay đổi trang phục, tư thế và cách tạo dáng theo prompt. Không thể bảo đảm giống 100% vì kết quả phụ thuộc model/API và ảnh đầu vào.

Mục đích tham chiếu (Reference Purpose)

Chế độ tạo prompt: không gọi API và không phát sinh phí. Bấm “Tạo prompt xem trước” rồi sao chép prompt để dùng trong ComfyUI hoặc công cụ khác.

4. Kết quả (Generated Result)

Ảnh hiển thị bên dưới là kết quả trả về từ API. Nút tải về lưu dữ liệu ảnh gốc nhận được, không phải ảnh chụp màn hình hay ảnh thu nhỏ.

Chưa có ảnh

Sau khi tạo ảnh thành công, ảnh sẽ xuất hiện ở đây.

5. Thiết lập backend (Backend Setup)

  1. Triển khai thư mục backend lên dịch vụ Node.js riêng như Render.
  2. Đặt OPENAI_API_KEY và/hoặc GEMINI_API_KEY trong phần Environment Variables của backend.
  3. Đặt ALLOWED_ORIGINS thành URL GitHub Pages của thím.
  4. Copy URL backend vào ô ở đầu trang, sau đó bấm kiểm tra bằng nút tạo ảnh.
Bảo mật: Không commit file .env. Không đặt API key trong index.html, GitHub Pages, localStorage hoặc mã JavaScript phía trình duyệt.

Lưu ý chi phí: API tính phí riêng theo nhà cung cấp/model. “Cao nhất” được ánh xạ sang chế độ chất lượng tối đa mà model được cấu hình hỗ trợ; kích thước thực tế tùy model và tỷ lệ ảnh.
