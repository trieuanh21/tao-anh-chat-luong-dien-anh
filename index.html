AI Image Studio V6.4

Tạo prompt, gửi ảnh tham chiếu đến OpenAI hoặc Gemini API, xem kết quả và tải ảnh gốc. Giao diện tiếng Việt kèm thuật ngữ tiếng Anh trong ngoặc.

GitHub Pages (giao diện)Backend riêng (máy chủ trung gian)Không lưu API key trong trình duyệt

1. Kết nối dịch vụ (Provider Setup)

Địa chỉ backend được công khai; API key chỉ được lưu trong file .env trên backend, tuyệt đối không nhập API key vào ô này.

Mật khẩu được gửi đến backend để xác thực; app chỉ giữ mã phiên trong bộ nhớ của tab hiện tại, không lưu mật khẩu hoặc mã phiên vào localStorage.

2. Nội dung ảnh (Image Brief)

Các ô đã được điền sẵn bằng một ví dụ hoàn chỉnh: cô gái Việt Nam mặc áo dài, cầm nón lá và bấm điện thoại trên ghế đá sân trường. Thím sửa theo ý mình hoặc xóa phần không cần; ô nào để trống sẽ được bỏ qua khi tạo prompt.

Bố cục và máy ảnh (Composition & Camera)

3. Ảnh tham chiếu (Reference Images)

Ảnh sẽ được gửi qua backend đến API đã chọn. Chỉ tải ảnh bạn có quyền sử dụng. Ảnh không được lưu vào GitHub Pages.

PNG, JPEG, WebP. Giới hạn mặc định 4 ảnh, mỗi ảnh tối đa 10 MB.

Mục đích tham chiếu (Reference Purpose)

Chưa kết nối backend. Hãy triển khai backend, cấu hình API key trong .env và nhập địa chỉ backend ở phía trên.

4. Kết quả (Generated Result)

Ảnh hiển thị bên dưới là kết quả trả về từ API. Nút tải về lưu dữ liệu ảnh gốc nhận được, không phải ảnh chụp màn hình hay ảnh thu nhỏ.

Chưa có ảnh

Sau khi tạo ảnh thành công, ảnh sẽ xuất hiện ở đây.

5. Thiết lập backend (Backend Setup)

  1. Triển khai thư mục backend lên dịch vụ Node.js riêng như Render.
  2. Đặt OPENAI_API_KEY và/hoặc GEMINI_API_KEY trong phần Environment Variables của backend.
  3. Đặt ALLOWED_ORIGINS thành URL GitHub Pages của thím.
  4. Copy URL backend vào ô ở đầu trang, sau đó bấm kiểm tra bằng nút tạo ảnh.
Bảo mật: Không commit file .env. Không đặt API key trong index.html, GitHub Pages, localStorage hoặc mã JavaScript phía trình duyệt.

Lưu ý chi phí: API tính phí riêng theo nhà cung cấp/model. “Cao nhất” được ánh xạ sang chế độ chất lượng tối đa mà model được cấu hình hỗ trợ; kích thước thực tế tùy model và tỷ lệ ảnh.
